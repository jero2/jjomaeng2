# tools (쪼맹 운영용)

- `render_feed.py` — 클로드 디자인 캔버스 아트보드 → 1080×1350 PNG. 사용법은 파일 맨 위 설명.
- `pixelate.py` — 사진 속 얼굴 모자이크.
- 공개 이미지 주소가 필요할 때(노션·업리카 업로드): PNG를 `feed/<글-slug>/`에 커밋·푸시하고
  `https://raw.githubusercontent.com/jero2/jjomaeng2/<커밋>/feed/<글-slug>/<파일>` 을 쓴다.
  (작업 공간에서 노션·업리카 업로드 주소로 직접 보내는 길은 막혀 있음)

운영 규칙 전체: 노션 「쪼맹 운영 시스템 (Claude 런북)」 페이지.
